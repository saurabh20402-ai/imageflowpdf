# ImageFlow

Browser-based productivity tools for PDFs, images, and files — fast, private, and free.

## What is ImageFlow?

ImageFlow is a modern SaaS platform providing browser-based file productivity tools. Every tool is designed to solve a single problem completely, work without friction, and respect user privacy by default.

No installation. No account required for core features. No unnecessary complexity. Just open the tool, do the task, and move on.

---

## Why ImageFlow?

Most file productivity tools force you to choose between convenience and trust. ImageFlow doesn't.

| | ImageFlow | Traditional Tools |
|---|---|---|
| **Sign-up** | Optional for core tools | Often required upfront |
| **Cost** | Free core functionality | Frequently subscription-gated |
| **Privacy** | Files stay on your device | Uploaded for storage/processing |
| **Speed** | Optimized for instant tasks | Designed for projects |
| **Simplicity** | One tool, one job | Bloated feature sets |

## Features

### Current Tools
- **PDF Tools** — Merge, split, compress, convert
- **Image Tools** — Resize, convert, optimize, crop
- **AI Utilities** — AI-powered file generation and enhancement

### Core Principles
- **Zero Friction** — no sign-up, install, or payment for core features
- **Privacy First** — files processed locally when possible
- **Built for Speed** — optimized for Core Web Vitals and sub-second interactions
- **Accessible** — WCAG 2.2 AA compliant, keyboard navigable, screen reader ready
- **SEO-Optimized** — discoverable, structured, properly indexed

## Getting Started

### Using ImageFlow

Visit [imageflow.in](https://imageflow.in) to start using the tools immediately — no installation or account required.

### Running Locally

```bash
git clone https://github.com/saurabh20402-ai/imageflowpdf.git
cd imageflowpdf
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## Tech Stack

- **Frontend**: Next.js, React, TypeScript
- **Styling**: CSS-in-JS with design tokens (no external CSS frameworks)
- **Deployment**: Vercel
- **Performance**: Optimized for Core Web Vitals, lazy loading, code splitting
- **Accessibility**: WCAG 2.2 AA, semantic HTML, ARIA only when necessary

## Development

### Prerequisites
- Node.js 18+
- npm or yarn

### Quick Start

1. **Clone the repository**
   ```bash
   git clone https://github.com/saurabh20402-ai/imageflowpdf.git
   cd imageflowpdf
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. **Build for production**
   ```bash
   npm run build
   npm start
   ```
